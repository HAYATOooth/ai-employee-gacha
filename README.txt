AI社員7人ガチャ 完成版

■内容
・社長＋6人＝7人をガチャ対象に収録
・1人引き／10連ガチャ
・カプセル演出
・UR / SSR / SR / R のレアリティ演出
・7人のキャラクター図鑑
・収集率（0〜100%）
・ガチャ回数の保存
・ブラウザのlocalStorageに進行状況を保存
・スマホ対応／GitHub Pagesなどの静的サイトで公開可能

■起動
index.htmlをブラウザで開いてください。

■GitHub Pages公開
1. ZIPを解凍
2. index.html と images フォルダをGitHubリポジトリのトップ階層へアップロード
3. Settings → Pages → Deploy from a branch → main / root → Save

※画像ファイルも公開リポジトリに含まれます。
